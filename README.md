# Mihon AdFree

### Independent ad-free build of Mihon
Discover and read manga, webtoons, comics, and more – without donation popups, "Support Us" screens or Patreon links.

[![CI](https://img.shields.io/github/actions/workflow/status/JumpmanSr/mihon/build.yml?labelColor=27303D)](https://github.com/JumpmanSr/mihon/actions/workflows/build.yml)
[![License: Apache-2.0](https://img.shields.io/github/license/JumpmanSr/mihon?labelColor=27303D&color=0877d2)](/LICENSE)

## Download

[![Mihon AdFree](https://img.shields.io/github/v/release/JumpmanSr/mihon.svg?maxAge=3600&label=Stable&labelColor=06599d&color=043b69)](https://github.com/JumpmanSr/mihon/releases/latest)

*Requires Android 8.0 or higher.*

This build is signed with a different key than the official app, so it can't be installed over it. Create a backup in the official app, uninstall it, install this build, then restore the backup. After that, the in-app updater checks this repository for updates.

## What's different

<div align="left">

* No one-time donation popup.
* No "Support Us" screen or More tab entry.
* No Patreon, OpenCollective or Discord links.
* In-app updates come from this repository's releases.

</div>

## Features

<div align="left">

* Local reading of content.
* A configurable reader with multiple viewers, reading directions and other settings.
* Tracker support: [MangaBaka](https://mangabaka.org), [MyAnimeList](https://myanimelist.net/), [AniList](https://anilist.co/), [Kitsu](https://kitsu.app/), [MangaUpdates](https://mangaupdates.com), [Shikimori](https://shikimori.one), [Bangumi](https://bgm.tv/), and [Hikka](https://hikka.io/) support.
* Categories to organize your library.
* Light and dark themes.
* Schedule updating your library for new chapters.
* Create backups locally to read offline or to your desired cloud service.
* Plus much more...

</div>
